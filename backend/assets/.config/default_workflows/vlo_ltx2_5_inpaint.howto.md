# LTX 2.5 Inpaint

Replaces a masked region of a video clip using LTX 2.5.

1. Mask the area you want to change on the clip.
2. Select that part of the timeline as the **Source video**.
3. Describe what should appear in the masked area in the prompt.
4. Pick a mask crop mode and resolution, then generate.
